# Дизайн-система «Глубина» (StepToLead, с 18.11.2026)

Код: frontend/app/theme.css (токены, шрифты, примитивы), components/Sidebar.module.css (навигация, блок
«Дизайн-система»), components/space-switcher.module.css. Витрина всех примитивов — /design.

## Идея
Портал — рабочее место маркетолога и витрина агентства. Премиум здесь — это спокойствие и точность: глубокий
ночной синий слоями вместо теней, один громкий элемент (заголовок страницы и большие числа шрифтом Unbounded),
всё остальное тихое. Фирменный мотив — «сигнальная линия»: выбранное (пункт меню, отмеченная строка, клиент в
переключателе) отмечено тонкой светящейся синей чертой слева — как шаг вперёд (Step).

## Шрифт
Onest — интерфейс (сделан для русского интерфейса, табличные цифры включены). Unbounded — заголовок страницы,
заголовки окон, крупные числа. Размеры: 12 / 13 / 14 (основной) / 16 / 18 / 22 / 28–40. Подписи — обычным
регистром, без капса и разрядки.

## Правила
- Синяя кнопка — одно главное действие на экране; остальные — тихие (secondary).
- Радиусы по иерархии: панели 16, окна 20, поля и кнопки 10, чипы — круглые.
- Статусы — чипы `.chip live|caution|alert|signal`, цвет только по смыслу.
- Движение только в ответ на действие: нажатие (scale .98, 120 мс), окно поднимается (180 мс), фокус —
  синее кольцо. prefers-reduced-motion отключает всё.
- Мобильная ширина 390 px — обязательна для каждого экрана.

## Порядок перевода экранов
1. Основа: токены, шрифты, примитивы, меню, переключатель клиента — сделано.
2. Ключевые экраны: Результат (портал клиента), CRM, Входящие, Аккаунты/Прогрев.
3. Остальные экраны по разделам; старые светлые цвета в модулях заменяются токенами.
