# Прогрев Telegram-аккаунтов (проект, 17.11.2026)

Цель: купленный аккаунт (tdata) за 2–3 недели выглядит для Telegram живым человеком — и только потом пишет
незнакомым людям, с плавно растущим лимитом. Всё — через прокси аккаунта, по расписанию «человека», без ИИ
по умолчанию (как прогрев почты: фразы-спинтакс), опционально ИИ из резерва агентства.

## Этапы аккаунта (stage)
| Этап | Дни | Что делает | Холодных первых касаний в день |
|---|---|---|---|
| 0. Подготовка | 0 | уникальная аватарка, имя, username, bio; скрыть номер (privacy); по желанию — завершить чужие сессии продавца | 0 |
| 1. Отлёжка | 1–2 | только «онлайн»: 3–6 заходов в день, чтение, ничего не пишет | 0 |
| 2. Пассив | 3–5 | вступает в 3–8 каналов из набора компании, читает ленту (просмотры), редкие реакции | 0 |
| 3. Свои | 5–10 | переписка со «своими» аккаунтами из общего пула: диалоги в 2–6 реплик, ответы, реакции, стикеры; взаимное добавление в контакты; групповые чаты по 3–5 аккаунтов | 0 |
| 4. Разгон | 8–21 | всё из этапов 2–3 + холодные касания по лестнице | 2 → 3 → 5 → 8 → 12 → лимит компании |
| 5. Готов | 21+ | поддерживающий прогрев (1–3 действия в день), холодные — по лимиту | лимит аккаунта/компании |

Лестница действует как «потолок»: действующий лимит = min(лимит аккаунта или компании, потолок прогрева).
Точечный лимит аккаунта выше потолка — только с галочкой «аккаунт уже прогрет» (переводит сразу в «Готов»).

## Защита (откаты)
- Спам-блок (@SpamBot) — проверка перед этапом 4 и раз в сутки; ограничен → откат на этап 3, холодных 0,
  повторная проверка через 24 ч. Повторный спам-блок → этап 3 на 7 дней.
- FloodWait/PeerFlood → пауза аккаунта (как в раннере), лестница не растёт в этот день.
- Нет ответов на холодные 3 дня подряд при ≥20 отправленных или жалобы (отписки «стоп») > 10% → лестница
  на ступень вниз.
- Ночь (часовой пояс компании) — никаких действий; у каждого аккаунта свой «распорядок» (сдвиг ±2 ч).
- Без рабочего прокси — ничего (как везде).

## Как «живёт» аккаунт (планировщик)
- У аккаунта на день — бюджет действий (этап × случайность ±30%), разложенный по «сессиям» 1–8 мин с паузами
  40–180 мин. В сессии: онлайн → прочитать 1–3 диалога/канала → (по этапу) реакция/ответ/сообщение → офлайн.
- Пары для переписки — из общего пула аккаунтов всех клиентов агентства (как общий пул прогрева почты, 1Б),
  не из одного прокси-подсети/одного клиента, если есть выбор; пара не повторяется чаще раза в 2 дня.
- Диалоги — сценарии из банка (знакомство, работа, погода, ссылка на статью, «скинь контакт», голосовое
  заменяется стикером), спинтакс; ответ приходит с задержкой 1–40 мин, иногда «прочитал и не ответил».
- Каналы — набор компании (по умолчанию нейтральные: новости, бизнес, город не задаётся) + свои.

## Данные
- telegram_accounts.warmup JSON: {stage, started_at, day, ceiling, next_session_at, today:{actions, sent,
  reactions, joined}, paused_until, last_rollback}.
- telegram_warmup_events: журнал (account_id, at, kind, details) — для экрана и разборов.
- Настройки компании (app_settings telegram:warmup:<ws>): вкл/выкл, интенсивность (мягко/норма/агрессивно),
  длительность (14/21/30 дней), каналы, участвовать в общем пуле.

## Экран
- «Telegram → Прогрев»: аккаунты по этапам (воронка), у каждого — день, этап, потолок холодных, действия
  сегодня, последнее событие, кнопки «Пауза», «Сбросить на этап…», «Отметить прогретым».
- В «Аккаунтах»: колонка «Прогрев: этап · день N · потолок K/день».
- Настройки компании: вкл/выкл, интенсивность, длительность, каналы.

## Порядок реализации
1. Модель + лестница потолка в раннере (лимит холодных) + экран-колонка. 2. Планировщик сессий: онлайн,
чтение, каналы, реакции. 3. Переписка «свои ↔ свои» и групповые чаты. 4. Откаты по спам-блоку/ответам.
5. Экран «Прогрев». Тесты: лестница/потолок, откаты, ночь, без прокси — ни одного подключения.
