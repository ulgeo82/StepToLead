# Telegram-аутрич компании (с 20.11.2026)

Экран: «Клиенты» → компания → «Аутрич компании» (/admin/clients/<id>/outreach). Сервер: /api/telegram-company
(backend/app/api/routes/telegram_company.py, services/tg_company.py), тесты — backend/tests/test_telegram_company.py.

Порядок: компания → прокси компании → аккаунты компании (tdata / по номеру, прокси назначается сам, прогрев) →
гипотезы (базы получателей) → рассылка.

- Гипотеза = кампания компании (campaigns) со своей базой: файл Excel/CSV, колонки username и first_message —
  первое сообщение своё у каждого получателя. При загрузке пропускаются дубли внутри гипотезы, люди из других
  гипотез этой компании (одному человеку компания пишет один раз) и стоп-лист Telegram.
- Первые сообщения отправляет ОДНА отмеченная гипотеза (у остальных daily_limit = 0). Остальные гипотезы
  продолжают работать, пока в них есть живые диалоги: ответы читаются и обрабатываются. Гипотеза без первых
  сообщений и без живых диалогов аккаунты не подключает.
- Настройки рассылки (ответы вручную/ИИ, ключ, промпт, часы тишины, часовой пояс, паузы, чёрный список) — одни на
  компанию; при сохранении копируются во все её гипотезы. Лимит первых касаний — компании/аккаунта (tg_limits).
- Аккаунты — все рабочие аккаунты компании (есть сессия и прокси, не «сессия слетела»/«заблокирован»), во всех
  её гипотезах; гипотезы одной компании делят аккаунты, чужая компания — нет.
- «Запустить рассылку» — проверки как при запуске кампании (база, аккаунты, ИИ, если включён); «Пауза» — вся компания.
- Результаты по гипотезам: в базе, ждут, отправлено, ответили (и %), интерес, отказ, не дошло.
